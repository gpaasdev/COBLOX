# 13 — KNOWLEDGE BASE & GLOSSARY

## 1. Project Glossary
- **ProfileStore:** Official Roblox data persistence library featuring session locking and automatic data reconciliation.
- **Rojo:** Tool allowing external IDE text editor workflows synced into Roblox Studio.
- **Dropper:** Tycoon object that generates drop parts producing income upon collector contact.
- **Atomic Trade:** Synchronous item/currency exchange guaranteeing either total completion or total rollback.
