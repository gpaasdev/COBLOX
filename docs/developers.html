🛡️ Pilar Utama Arsitektur Teknis

Zero-Trust Validation

Validasi server-side tanpa kompromi untuk seluruh `RemoteEvent` & `RemoteFunction`. Termasuk jarak fisik (≤ 15 studs) dan sanitasi runtime `typeof()`.

ProfileStore v3 Lock

Perlindungan *session-locking* murni untuk mencegah duplikasi item, *rollback*, atau kehilang data pemain saat server Roblox mati mendadak.

Mobile Budget <2.5GB

Optimasi memori RAM bawah batasan 2.5 GB untuk perangkat mobile low-end melalui *ObjectPool pattern* dan batas maksimal 20 partikel aktif per emitter.

Roblox OpenCloud API

Sinkronisasi *live service* dua arah via MessagingService REST API untuk *promo code claiming*, pengumuman darurat, dan ekspor telemetri.

-- Server-Authoritative Remote Event Listener with Distance & Type Validation
local function OnCraftRequested(player: Player, recipeId: string, pedestalInstance: Instance)
  if typeof(recipeId) ~= "string" or typeof(pedestalInstance) ~= "Instance" then
    return warn("Security Violation: Invalid payload types from", player.Name)
  end

  -- Distance Check (≤ 15 studs)
  local distance = (player.Character.PrimaryPart.Position - pedestalInstance.Position).Magnitude
  if distance > 15 then
    return warn("Distance Check Failed:", distance, "studs")
  end
end
# Roblox OpenCloud Web-to-Game LiveOps Broadcast Script
import requests, json

API_KEY = "rbx_opencloud_liveops_key_secret"
UNIVERSE_ID = "7894561230"

url = f"https://apis.roblox.com/messaging-service/v1/universes/{UNIVERSE_ID}/topics/LiveBroadcast"
headers = {"x-api-key": API_KEY, "Content-Type": "application/json"}
payload = {"message": json.dumps({"type": "PROMO_CLAIM", "code": "ALPHA2026"})}

response = requests.post(url, headers=headers, json=payload)
print(f"Status Broadcast: {response.status_code}")
