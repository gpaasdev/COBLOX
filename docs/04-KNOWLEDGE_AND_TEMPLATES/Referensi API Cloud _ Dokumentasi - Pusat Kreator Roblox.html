Referensi API Cloud

*Konten ini diterjemahkan menggunakan AI (Beta) dan mungkin mengandung kesalahan. Untuk melihat halaman ini dalam bahasa Inggris, klik di sini.

Dengan Open Cloud, Anda dapat mengakses sumber daya Roblox melalui API REST standar, yang memungkinkan Anda membangun segalanya mulai dari alat otomatisasi baris perintah hingga aplikasi web yang kompleks. Anda dapat memperbarui permainan, memulai kembali server, bekerja dengan penyimpanan data dan penyimpanan memori Anda, mengelola pembatasan pengguna, mendaftar item inventaris, dan banyak lagi.

Referensi ini dibagi menjadi dua bagian:

  • Sebuah bagian yang memisahkan endpoint berdasarkan fitur (Avatar, Game Pass, Pengguna, dll.)
  • Sebuah bagian yang memisahkan endpoint berdasarkan domain (URL dasar)

Kedua bagian memuat daftar lengkap endpoint API yang tersedia. Kami merekomendasikan bagian fitur karena membantu mengonsolidasikan endpoint berdasarkan kasus penggunaan, tetapi pengembang Open Cloud yang berpengalaman mungkin lebih suka menjelajahi berdasarkan domain.

  • Setiap kali memungkinkan, gunakan endpoint yang mendukung kunci API atau OAuth 2.0 untuk autentikasi. Mereka memiliki jaminan stabilitas yang kuat dan menerima pembaruan secara teratur.

  • API warisan menggunakan autentikasi berbasis cookie, dapat mengadopsi perubahan besar tanpa pemberitahuan, dan memiliki jaminan stabilitas yang minimal. Kami tidak merekomendasikan mereka untuk aplikasi produksi.

Roblox juga menawarkan webhook, yang dapat memberi tahu aplikasi Anda ketika peristiwa tertentu terjadi, seperti pengembalian dana atau perubahan pada langganan.

Mulai dengan Open Cloud

  1. Siapkan autentikasi untuk aplikasi Anda.

    Lihat dokumentasi untuk cara menggunakan kunci API atau OAuth 2.0. Kunci API adalah cara termudah untuk memulai.

  2. Uji panggilan API menggunakan alat seperti Postman dengan deskripsi OpenAPI atau aplikasi contoh OAuth 2.0.

  3. Tinjau panduan sumber daya untuk walkthrough dari awal hingga akhir menggunakan API tertentu.

  4. Jelajahi navigasi kiri untuk daftar lengkap fitur, pola API umum, tipe, dan kode kesalahan.

Buat permintaan dalam permainan

HttpService memungkinkan Anda membuat permintaan HTTP ke subset endpoint Open Cloud. Untuk informasi lebih lanjut, lihat Permintaan HTTP dalam permainan.
