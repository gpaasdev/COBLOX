# 🤖 COBLOX AI Creative Workflow

> **Collaborating with AI IDE Agents**
> COBLOX heavily utilizes AI agents (Antigravity, Cursor, Claude Code) for development. This document defines the Standard Operating Procedure (SOP) for how AI agents should generate, review, and validate creative assets and UI code.

---

## 1. The Role of the AI Agent

The AI Agent is a **Senior Technical Artist and UX Engineer**. It is responsible for:
1. Generating UI/UX code (Luau, React-Roblox) that strictly adheres to the [Style Guide](../03-PRODUCT_AND_DESIGN/STYLE_GUIDE.md).
2. Generating structured JSON metadata for new items/machines that adheres to the [Content Bible](CONTENT_BIBLE.md).
3. Validating folder structures, file naming, and metadata consistency.

The AI Agent is **NOT** responsible for generating final 3D meshes or final raster art without explicit human approval and guidance.

---

## 2. Asset Generation Workflow

When an AI Agent is tasked with generating a new UI component or Content Data:

### Step 1: Research & Reference
- The Agent MUST read `STYLE_GUIDE.md`, `UI_COMPONENT_LIBRARY.md`, and `CONTENT_BIBLE.md` before writing code or data.
- The Agent must identify existing similar components to ensure reusability.

### Step 2: Proposal (Implementation Plan)
- The Agent must create an `implementation_plan.md` artifact outlining the proposed component anatomy, state changes, or data structure.
- Wait for human approval (`request_feedback = true`).

### Step 3: Execution & Checklist
- The Agent executes the code.
- The Agent MUST run a self-review against the **Design QA Checklist** (Section 3 below).

---

## 3. Automated Design QA Checklist

Before the Agent marks a task as complete, it must verify:

- [ ] **No Placeholders:** All text, icons, and colors are final production values, not temporary filler.
- [ ] **Grid Compliance:** All padding, margins, and sizes adhere to the 4px/8px modular grid.
- [ ] **Typographic Hierarchy:** All fonts use the correct weight and size defined in the Style Guide. `UIStroke` is applied if necessary.
- [ ] **Naming Conventions:** All files and instances use the correct casing (`PascalCase`, `snake_case`).
- [ ] **Terminology:** All labels and copy use the official terminology (e.g., "Refine" instead of "Smelt").
- [ ] **Performance Validation:** UI instances are pooled if applicable. No expensive continuous `RenderStepped` loops for simple UI animations.

---

## 4. Metadata Validation & Versioning

- When the Agent modifies content definitions (e.g., adding a new material to `content/materials.json`), it must trigger the registry generation script (`scripts/registry/generate_registry.py`).
- The Agent must ensure the immutable snapshot (`registry/latest.json`) is updated and linked correctly.
- Commit messages generated by the Agent must clearly state which Creative OS rules were applied (e.g., `feat(ui): Add MachineCard component per UI_COMPONENT_LIBRARY guidelines`).
