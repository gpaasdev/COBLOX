# **📋 LAPORAN QA KOMPREHENSIF — COBLOX (Cyber Alchemist Sanctum)**

## **1\. RINGKASAN EKSEKUTIF**

Game: **CoBloX** — Tycoon/Sanctum Alchemist dengan 57 service server, 40+ controller client, sistem ekonomi multi-currency, combat, pets, alchemy, quests, dan monetisasi. Arsitektur skala produksi yang sangat ambisius.  
**Status Overall: BUGGY dengan Issue Kritis**

* **Kritis:** 3 bug keamanan ekonomi (exploit crafting/consumable)  
* **Tinggi:** 10+ badge tidak terkonfigurasi, fluktuasi FPS, localization tidak konsisten  
* **Sedang:** Duplikasi modul, PartCache folder berlebih, string hardcoded  
* **Rendah:** Variable shadowing, duplicate conditional check, button state tidak reset

## **2\. FUNGSIONALITAS**

🔴 **KRITIS — Security/Economy Exploit**

### **Bug \#1: RecipeService.CraftGrid3x3 — Tidak Validasi Bahan Craft**

* **Path:** ServerScriptService.Server.Services.RecipeService  
* **Masalah:** Fungsi crafting menerima item ID dari client dan langsung menambahkan hasil craft ke inventory TANPA memeriksa apakah player benar-benar memiliki bahan. Bahan tidak pernah dikurangi dari inventory.  
* **Dampak:** Player dapat craft item apapun (QuartzAltar, AstralGenerator, PyroBuffPotion) tanpa memiliki material. Eksploitasi ekonomi total.  
* **Prioritas:** P0 — Wajib fix sebelum release

### **Bug \#2: RecipeService.SmeltOre — Tidak Validasi Ore & Fuel**

* **Path:** ServerScriptService.Server.Services.RecipeService  
* **Masalah:** Fungsi smelt menerima rawOreItem dan fuelItem dari client tanpa verifikasi kepemilikan atau pengurangan dari inventory.  
* **Dampak:** Player dapat smelt ore tak terbatas tanpa bahan.  
* **Prioritas:** P0

### **Bug \#3: ConsumableMutationService.ConsumePotion — Tidak Cek Inventory**

* **Path:** ServerScriptService.Server.Services.ConsumableMutationService  
* **Masalah:** Fungsi consume potion memberikan efek (WalkSpeed 45, MaxHealth 500\) berdasarkan potionName dari client TANPA memverifikasi kepemilikan potion.  
* **Dampak:** Player dapat menggunakan potion apapun (ElixirSurge, MythicElixir) tanpa meililikinya, secara unlimited.  
* **Prioritas:** P0

🟡 **SEDANG — Functional Issues**

### **Bug \#4: AdRewardController — Duplicate Conditional Check**

* **Path:** StarterPlayer.StarterPlayerScripts.Client.Controllers.AdRewardController  
* **Line 53-54:** if requestRemote then di-check dua kali berturut-turut (kode duplikat)

### **Bug \#5: AdRewardController — Button State Tidak Reset saat Error**

* Tombol Active \= false saat klik, hanya reset ke true pada callback sukses. Jika remote gagal, tombol permanen non-aktif.

### **Bug \#6: FTUEController — Variable Shadowing**

* milestone4: TextLabel dideklarasikan dua kali (line 16 dan 301\)

### **Bug \#7: OfflineEarningsService — Fixed 2-Hour Earnings**

* Player menerima 36,000 coins saat join tanpa perhitungan waktu offline sebenarnya. Bisa di-exploit dengan rejoin berulang.

## **3\. COMPATIBILITY**

🟡 **ISU — Platform**

### **Isu \#1: StreamingController — Platform Limitation**

* **Log:** StreamingPauseMode signal unavailable on this platform, skipping listener.  
* **Status:** Handled dengan gracefully skip, tapi mengindikasikan kompatibilitas streaming belum penuh

### **Isu \#2: PerformanceMonitorController — FPS Throttling Fluktuatif**

* Log menunjukkan toggling cepat antara "Low FPS detected\! Throttling particles..." dan "FPS stabilized. Restoring particles..."  
* Physics FPS terdeteksi 60, namun render FPS dilaporkan fluktuatif  
* **Dampak:** Pada device low-end, particle effects akan terus toggle on/off menyebabkan visual flicker

### **Isu \#3: Tidak Ada StarterPack/Tools**

* StarterPack kosong. Player tidak mendapat tool awal. Items hanya didapat melalui gameplay. Pastikan ini by design, bukan konfigurasi yang hilang.

✅ **PASS — Compatibility yang Baik**

* PolicyComplianceService aktif dan mendeteksi Paid Random Items Restricted: false  
* GraphicsOptimizationController auto-detect FPS dan menyesuaikan quality  
* Mobile touch support diaktifkan di CombatController

## **4\. REGRESI**

🟡 **REGRESI POTENSIAL**

### **Regresi \#1: Duplicate Localization Modules**

* Dua modul GameLocalization ditemukan:  
  * ReplicatedStorage.Shared.Localization.GameLocalization  
  * ReplicatedStorage.Localization.GameLocalization  
* Keduanya memiliki key yang mirip tapi translation sedikit berbeda  
* **Risiko:** Controller yang berbeda mungkin me-require modul yang berbeda, menyebabkan inkonsistensi terjemahan

### **Regresi \#2: 5 PartCache\_Part Folders di Workspace**

* Ditemukan 5 folder PartCache\_Part di workspace dengan ukuran berbeda (0, 20, 50, 30, 20 parts)  
* **Risiko:** Memory leak jika PartCache tidak di-garbage collect dengan benar  
* Folder dengan 0 descendants (kosong) mengindikasikan cleanup yang tidak sempurna
