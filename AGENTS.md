# COBLOX Development Patterns

## Generated Registries — Data/Func Separation
**NEVER** iterate a Generated*Registry directly with `pairs()`. Functions (Get, GetAll, etc.) are stored in the registry table alongside data.

✅ **CORRECT:**
```luau
local data = Registry.GetAll()  -- returns {_data} table (data only)
for id, entry in pairs(data) do
    -- entry is always a data table, never a function
end
```

❌ **WRONG:**
```luau
for id, entry in pairs(Registry) do  -- iterates BOTH functions AND data
    -- entry might be a function!
end
```

All Generated*Registry files (`src/Shared/Config/Generated*.luau`) are auto-generated by `tools/content_pipeline.py`. They use an internal `_data` table — NEVER modify them manually.

## ControllerRegistry — Colon Notation
Always use colon notation for Init/Start:
```luau
-- ControllerRegistry calls: controller:Init(ControllerRegistry), controller:Start(ControllerRegistry)
function MyController.Init(self, Registry: any)
    self.maid = Maid.new()
end
```

**Always** add `self` as the first parameter when defining Init/Start.

## ContextActionService — No Return Value
`ContextActionService:BindAction()` returns **nil** (void function). Do NOT wrap in `GiveTask`:
```luau
-- ❌ WRONG: BindAction returns nil, GiveTask(nil) throws
self.maid:GiveTask(ContextActionService:BindAction("Name", handler, ...))

-- ✅ CORRECT: Use UnbindAction for cleanup
ContextActionService:BindAction("Name", handler, ...)
self.maid:GiveTask(function()
    ContextActionService:UnbindAction("Name")
end)
```

## Self in Helper Functions
Helper functions called from Init/Start that use `self.maid` must also receive `self`:
```luau
function MyController.Init(self, Registry)
    self.maid = Maid.new()
    self:_CreateUI()  -- colon notation passes self
end

function MyController._CreateUI(self)  -- self parameter required
    self.maid:GiveTask(someEvent:Connect(function() end))
end
```

## DropRate Format
Spirit DropRate values in `Content/Data/Spirits/*.json` use the format `"1.5%"` (string with `%` suffix). When parsing in code:
```luau
local dropStr = tostring(spirit.DropRate):gsub("%%", "")
local dropWeight = tonumber(dropStr)  -- returns 1.5
```
